Tout a été lancé depuis **PowerShell (administrateur) sur SRV01**, connecté en `NOVACORP\Administrateur`. Les commandes ci-dessous sont les versions **finales** (celles qui ont réellement été exécutées, après corrections). Elles sont rejouables : chaque création teste d'abord l'existence.

### A2. Module AD, groupes de domaine local, dossiers, droits NTFS, partages SMB

```powershell
Install-WindowsFeature RSAT-AD-PowerShell | Out-Null
$svc = "Finance","IT","RH","Support"

# 1. Groupes DL : RW (modification) et R (lecture) par service
foreach ($s in $svc) {
    foreach ($p in "RW","R") {
        $n = "DL_${s}_${p}"
        if (-not (Get-ADGroup -Filter "Name -eq '$n'")) {
            New-ADGroup -Name $n -GroupScope DomainLocal -GroupCategory Security -Description "Acces $p au partage $s"
        }
    }
}

# 2. Dossiers
foreach ($s in $svc) { New-Item -ItemType Directory -Path "D:\Shares\$s" -Force | Out-Null }

# 3. NTFS : héritage coupé, uniquement des groupes (SID : Administrateurs = S-1-5-32-544, SYSTEM = S-1-5-18)
foreach ($s in $svc) {
    $path = "D:\Shares\$s"
    icacls $path /inheritance:r | Out-Null
    icacls $path /grant "*S-1-5-32-544:(OI)(CI)F" "*S-1-5-18:(OI)(CI)F" | Out-Null
    icacls $path /grant "NOVACORP\DL_${s}_RW:(OI)(CI)M" | Out-Null
    icacls $path /grant "NOVACORP\DL_${s}_R:(OI)(CI)RX" | Out-Null
}

# 4. Partages SMB
foreach ($s in $svc) {
    New-SmbShare -Name $s -Path "D:\Shares\$s" `
        -FullAccess "NOVACORP\Admins du domaine" `
        -ChangeAccess "NOVACORP\DL_${s}_RW" `
        -ReadAccess "NOVACORP\DL_${s}_R" `
        -FolderEnumerationMode AccessBased
}
```

### A3. Groupes globaux `GG_*`, alimentation et imbrication AGDLP

Les groupes globaux n'existaient pas encore : ils ont été créés dans l'OU de chaque service, alimentés avec les utilisateurs de l'OU, puis imbriqués dans les `DL_*`.

```powershell
$base = "OU=NovaCorp,DC=novacorp,DC=test"
$svc  = "Finance","IT","RH","Support"

# 1. Groupes globaux (Direction incluse)
foreach ($s in $svc + "Direction") {
    $n  = "GG_$s"
    $ou = "OU=$s,$base"
    if (-not (Get-ADGroup -Filter "Name -eq '$n'")) {
        New-ADGroup -Name $n -GroupScope Global -GroupCategory Security -Path $ou -Description "Metier $s"
    }
}

# 2. Utilisateurs de chaque OU -> groupe global correspondant
foreach ($s in $svc + "Direction") {
    $users = Get-ADUser -Filter * -SearchBase "OU=$s,$base" -SearchScope Subtree
    if ($users) { Add-ADGroupMember -Identity "GG_$s" -Members $users -ErrorAction SilentlyContinue }
    "GG_{0} : {1} utilisateur(s) dans l'OU" -f $s, @($users).Count
}

# 3. AGDLP : GG métier -> DL_RW de son service ; GG_Direction -> DL_R de tous les services
foreach ($s in $svc) {
    Add-ADGroupMember -Identity "DL_${s}_RW" -Members "GG_$s"        -ErrorAction SilentlyContinue
    Add-ADGroupMember -Identity "DL_${s}_R"  -Members "GG_Direction" -ErrorAction SilentlyContinue
}
```

### A5. Délégation Helpdesk (challenge 🟠) — état réel

`GG_HELPDESK` a été créé par un collègue. Le relevé de l'AD montre des ACE sur les objets `computer` uniquement, donc **le bloc de délégation sur les objets `user` n'est pas appliqué à ce jour**. Le bloc ci-dessous est celui à lancer, **après accord du collègue** (il ajoute des droits, il n'en retire aucun) :

```powershell
$target = "OU=NovaCorp,DC=novacorp,DC=test"
$ns   = (Get-ADGroup GG_HELPDESK).SID
$sch  = (Get-ADRootDSE).schemaNamingContext
function G($n) { [guid](Get-ADObject -SearchBase $sch -LDAPFilter "(lDAPDisplayName=$n)" -Properties schemaIDGUID).schemaIDGUID }
$user  = G "user"
$reset = [guid]"00299570-246d-11d0-a768-00aa006e0529"     # droit étendu Reset Password

$acl = Get-Acl "AD:$target"
$mk  = { param($rights,$guid) New-Object System.DirectoryServices.ActiveDirectoryAccessRule($ns,$rights,"Allow",$guid,"Descendents",$user) }
$acl.AddAccessRule((& $mk "ExtendedRight" $reset))
foreach ($a in "lockoutTime","pwdLastSet","telephoneNumber","mail","title","department","physicalDeliveryOfficeName","description") {
    $acl.AddAccessRule((& $mk "WriteProperty" (G $a)))
}
Set-Acl "AD:$target" $acl
```

La cible `OU=Users` du TP n'existe pas dans cet annuaire : la délégation est posée sur `OU=NovaCorp` (comptes utilisateurs des services, hors compte `Administrateur`).

## Partie C — Contrôle global en une passe

Ce script ne modifie rien et affiche `[PASS]` / `[FAIL]` pour les points B1 à B7. Il suppose le modèle du TP02 (4 services plus Direction en lecture).

```powershell
$svc = "Finance","IT","RH","Support"
function R($ok, $msg) { if ($ok) { Write-Host "[PASS] $msg" -ForegroundColor Green } else { Write-Host "[FAIL] $msg" -ForegroundColor Red } }

$v = Get-Volume -DriveLetter D -ErrorAction SilentlyContinue
R ($v -and $v.FileSystemType -eq 'NTFS') "Volume D: NTFS"

foreach ($s in $svc) {
    $path = "D:\Shares\$s"
    R (Test-Path $path) "Dossier $path"

    $sh = Get-SmbShare -Name $s -ErrorAction SilentlyContinue
    R ($sh -and $sh.Path -eq $path) "Partage \\SRV01\$s -> $path"
    R ($sh -and [string]$sh.FolderEnumerationMode -eq 'AccessBased') "Partage $s : énumération basée sur l'accès"

    if ($sh) {
        $acc = @(Get-SmbShareAccess -Name $s)
        $badShare = @($acc | Where-Object { $_.AccountName -notmatch '^NOVACORP\\(DL_|Admins du domaine)' -and $_.AccountName -notmatch '^(BUILTIN|AUTORITE NT|NT AUTHORITY)\\' })
        R ($badShare.Count -eq 0) "Partage $s : uniquement des groupes ($(($acc.AccountName) -join ', '))"
    }

    if (Test-Path $path) {
        $acl = Get-Acl $path
        R $acl.AreAccessRulesProtected "NTFS $s : héritage coupé"
        $bad = @($acl.Access | Where-Object {
            $sid = $_.IdentityReference.Translate([System.Security.Principal.SecurityIdentifier]).Value
            $sid -notin 'S-1-5-32-544','S-1-5-18' -and $_.IdentityReference.Value -notlike 'NOVACORP\DL_*' })
        R ($bad.Count -eq 0) "NTFS $s : aucun compte hors Administrateurs / SYSTEM / DL_*"
    }

    foreach ($p in "RW","R") {
        $g = Get-ADGroup -Filter "Name -eq 'DL_${s}_${p}'" -ErrorAction SilentlyContinue
        R ($g -and [string]$g.GroupScope -eq 'DomainLocal') "Groupe DL_${s}_${p} (DomainLocal)"
    }
    $gg = Get-ADGroup -Filter "Name -eq 'GG_$s'" -Properties Members -ErrorAction SilentlyContinue
    R ($gg -and [string]$gg.GroupScope -eq 'Global' -and $gg.Members.Count -gt 0) "Groupe GG_$s (Global, $($gg.Members.Count) membre(s))"
    $rw = Get-ADGroup -Filter "Name -eq 'DL_${s}_RW'" -Properties Members -ErrorAction SilentlyContinue
    R ($gg -and $rw -and ($rw.Members -contains $gg.DistinguishedName)) "GG_$s est membre de DL_${s}_RW"
    $r = Get-ADGroup -Filter "Name -eq 'DL_${s}_R'" -Properties Members -ErrorAction SilentlyContinue
    $dir = Get-ADGroup -Filter "Name -eq 'GG_Direction'" -ErrorAction SilentlyContinue
    R ($dir -and $r -and ($r.Members -contains $dir.DistinguishedName)) "GG_Direction est membre de DL_${s}_R"
}
```

Un `[FAIL]` indique le point à revoir dans la partie B correspondante.
